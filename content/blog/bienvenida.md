Este es el primer post del blog. Acá voy a ir dejando notas, aprendizajes y avances de proyectos a modo de registro personal.

## Cómo publicar

Cada entrada es un archivo Markdown dentro de `content/blog/`. Para publicar una nueva:

1. Crear un archivo `mi-post.md` en `content/blog/`.
2. Completar el encabezado (`title`, `date`, `excerpt`) y escribir el contenido en Markdown debajo.
3. Hacer commit y push — Vercel despliega automáticamente.

No hace falta base de datos ni panel de administración: el propio repositorio es el registro de publicaciones.
